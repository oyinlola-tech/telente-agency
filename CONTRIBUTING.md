# Contributing

Thanks for your interest in contributing.

## Workflow
1. Create a feature branch.
2. Keep changes focused and well-tested.
3. Submit a clear pull request describing the changes.

## Development Notes
- Frontend uses Vite + React + TypeScript.
- Backend uses Node.js + Express + MySQL.
- Ensure `.env` files are configured before running the apps.

## Code Style
- Prefer explicit, readable code over cleverness.
- Keep components and modules small and focused.
