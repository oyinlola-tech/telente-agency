# Telente Technologies

Official website and admin platform for Telente Technologies.

Maintainer: Oluwayemi Oyinlola Michael  
Portfolio: oyinlola.site

## Stack
- Frontend: Vite + React + TypeScript + Tailwind
- Backend: Node.js + Express + MySQL

## Environment
Frontend values are required in `.env`:
- `VITE_API_URL`
- `VITE_COMPANY_NAME`
- `VITE_PORTFOLIO_URL`

Backend values are required in `backend/.env` (see `backend/.env.example`).

## Frontend Setup
```
npm install
npm run dev
```

## Backend Setup
```
cd backend
npm install
npm run seed
npm run dev
```
